# Valores ocultos na visualização da PCB

Os valores dos footprints já estavam nas camadas F.Fab/B.Fab, fora da serigrafia F.SilkS/B.SilkS. Foram ocultados os38 campos ainda visíveis, preservando os6 já ocultos. Isso altera somente a visualização dos campos Value no editor.

Conteúdo dos valores, referências, camadas, posição, rotação, geometria, pads, redes, contorno e todos os demais dados preservados por comparação estrutural. Esquemático preservado por SHA-256. Os valores continuam disponíveis nas propriedades e no esquema/lista de materiais.
