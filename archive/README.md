# Histórico preservado

| Caminho | Conteúdo |
| --- | --- |
| `PROJECT_HISTORY.md` | README técnica anterior, com o histórico das revisões |
| `implementation/` | Experimentos, propostas e snapshots antes de cada alteração |
| `review/` | Auditorias, evidências e relatórios anteriores |
| `backups/kicad/` | Backup automático existente antes da reorganização |
| `legacy-projects/` | Arquivo auxiliar antigo do projeto autorroteado |

Os scripts aqui são registros de intervenções históricas e podem conter os
caminhos originais. Não constituem o fluxo atual de reconstrução da placa.
Os geradores atuais de modelos ajustados foram separados em
[`scripts/models3d/`](../scripts/models3d/).

Os conteúdos de PCB, esquema, modelos e backups foram preservados. Os links
Markdown foram ajustados quando apontavam a arquivos movidos. O mapa de
caminhos está em [`docs/organization-map.json`](../docs/organization-map.json).

O KiCad pode voltar a criar uma pasta automática `oneTesla-backups/` na raiz.
