# PCB — active project

Open [oneTesla.kicad_pro](oneTesla.kicad_pro) in KiCad.

| Path | Purpose |
| --- | --- |
| `oneTesla.kicad_sch` | Electrical schematic |
| `oneTesla.kicad_pcb` | PCB layout |
| `oneTesla.kicad_dru` | Custom design rules |
| `library/oneTesla.kicad_sym` | Local symbols |
| `library/*.pretty/` | Local footprint libraries |
| `library/3dmodels/` | 3D models and source notices |
| `fp-lib-table`, `sym-lib-table` | Local library references |

Library paths use `${KIPRJMOD}/library/...`; keep the libraries alongside the project.
See [PCB deliverables](../../production/pcb/) and [tools](../../scripts/README.md).
